Confirm `xcodegen` is on PATH (it lives as a standalone binary in `~/bin`, persisted via

Then open the generated project:


## 3. Build + run on the Simulator — verify the four unverified things

In Xcode: pick an **iPhone 15/16 Pro simulator**, **Cmd+R** to build & run.

Verify each, in order:

### A. Space Grotesk actually loads (Phase 0)
- Look at the **tier letters** (S/A/B/C/F badges in My Tiers / tier picker). They should
  render in Space Grotesk, not the system rounded font.
- **Silent-fallback trap:** if a custom-font PostScript name is wrong, SwiftUI silently
  falls back to the system font and *looks fine-ish*. Compare the tier letters against the
  system font — Space Grotesk has a distinctly geometric, slightly condensed look.
- If it fell back: check `UIAppFonts` in `project.yml` lists all four TTFs, and that
  `Font.grotesk` in `DesignSystem.swift` uses the exact PostScript names
  (`SpaceGrotesk-Regular/Medium/SemiBold/Bold`).

### B. Shareable Lists (Phase 1)
- **My Tiers tab → toolbar `list.star` icon** → Lists view.
- Create a list ("Top 10 Tacos"), add a few restaurants, reorder, rename, toggle public.
- Open a list → **Share menu**: "Share as image" should produce the numbered Top-N card;
  "Share link" should produce a `stier://list/<id>` link.
- **Requires the rules deploy from step 0** — if create/fetch silently returns empty,
  the rules aren't published yet.

### C. Food Wrapped (Phase 2a)
- **My Stats → Share button (toolbar)** → renders the stats card (rank pill + ranked /
  S-tier / visited / top cuisine tiles + most-explored area). Confirm the share sheet
  offers the PNG.

### D. Taste Match Leaderboard (Phase 2b — newest)
- **Community tab → Friends board → `trophy` toolbar icon** (beside the clock/activity
  icon) → the leaderboard.
- With no friends followed: shows the "No friends yet" + invite state.
- To exercise scoring you need at least one followed account that has ranked some of the
  same restaurants — then confirm: friends sorted best-match-first, top 3 show trophy
  medals, match % + "N shared · agree on M" line, and no-overlap friends sink to the
  bottom as "No overlap yet."
- Tap a matched friend → opens the existing Taste Match compare view (should NOT re-fetch
  — it reuses the placements the leaderboard already pulled).

### Also watch the Xcode console while poking around
- Firebase/Firestore errors (esp. **permission-denied on `lists`** → rules not deployed).
- No crashes switching tabs / opening sheets.

## 4. Archive + upload to TestFlight

Once A–D check out:

1. Xcode → **Product → Scheme → Edit Scheme**: Run destination set, Release config for
   Archive.
2. Select **Any iOS Device (arm64)** as the destination (not a simulator).
3. **Product → Archive.**
4. In the Organizer: **Distribute App → App Store Connect → Upload.**
5. Build **94** appears in App Store Connect → TestFlight after processing.
6. **Harmless upload warnings:** dSYM-missing for Firebase / GoogleMobileAds / UMP — those
   vendor frameworks ship without dSYMs. Ignore them.
